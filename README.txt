Two Modes, "Move" and "Compare"


"Move" will allow you to move any folder/drive/contents to a targeted destination.
	Main Uses:
	-Onedrive/cloud storage->external drive
	-Storage Modem-> Another Storage Modem.

Move mode has the option to "copy via downloads" which temporarily copies the source to downloads which is needed to move mass files from OneDrive to an hdd/storage modem. It will delete them after the move is complete.

"Prevent Copies" is pretty self explanatory. If the source is moving over files to a destination and the destination already has the same name(and similar size) of a file being moved it will not move that file over if selected. if not selected it will add a numeral digit (i.e. test(1).txt) 

"Move, Don't copy" moves everything from source to target while removing the items from source, if you plan on keeping it as a copy don't select.





"Compare" will allow you to check a source and multiple target files to compare recourses. 
	Main uses:
	-make sure all contents copied/moved over correctly
	-Any folder compare to copies.
That's basically it. match via names/ sizing is the standard.
